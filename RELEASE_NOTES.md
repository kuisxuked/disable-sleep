## Disable Sleep 1.4.2

The English countdown label now reads **Until sleep allowed**. The label stays on one line in the compact panel. The paused marker now reads **(Paused)** in a small serif italic font.

Countdown pause/resume behavior from v1.4.1 is retained. Apple Silicon + Intel Universal build; macOS 13 or newer. This community build is locally signed, not Apple-notarized. See the README for first-launch instructions.
