About the first-launch macOS warning

This community build is locally signed, not Apple-notarized. If macOS blocks the download, use Privacy & Security → Open Anyway only if you trust the source. You never need to turn off system-wide security protections.

What does the switch change?

It changes pmset's system-wide disablesleep setting, including idle sleep, on battery and AC power. Quitting does not reset it. Turn the switch off to allow normal sleep again. Keep the Mac ventilated with its lid closed. See the README for the two narrowly scoped authorization rules and removal instructions.

Will a timer wake a sleeping Mac?

No. A timer needs the app running. If the deadline passes while the Mac is asleep or the app is closed, it catches up after wake or the next launch.
